# ADR 0003: GOTS v7.0 Rule-Based Compliance & Chemical Restriction Architecture

* **Status**: Accepted & Implemented (Core) / Expanding (RSL Supply Chain)
* **Date**: 2026-09-02
* **Deciders**: Engineering & Materials Science Team

---

## Context & Problem Statement

For bio-based materials and technical textiles to achieve commercial organic certification, formulations must adhere strictly to the **Global Organic Textile Standard (GOTS) Version 7.0**. 

Recommendations generated by machine learning models must not propose fiber blends or chemical processing auxiliaries that violate GOTS certification tiers, synthetic blending caps, or hazardous substance restrictions.

---

## Decision Drivers

1. **Deterministic Verification**: Compliance verification must be rule-based, deterministic, and auditable—never inferred probabilistically by black-box models.
2. **Certification Tier Distinctions**:
   * Grade A (*"Organic"*): $\ge 95\%$ certified organic fibers, $\le 5\%$ non-organic natural / synthetic fibers.
   * Grade B (*"Made with Organic"*): $\ge 70\%$ certified organic fibers, $\le 30\%$ non-organic (with synthetic polymers capped at $\le 10\%$, or $\le 25\%$ for sportswear/socks).
3. **Restricted Substance List (RSL)**: Immediate rejection of inputs containing prohibited chemicals (formaldehyde, toxic heavy metals, aromatic solvents, nano-particles, perfluorinated compounds).

---

## Decision Outcome

Implement a standalone, zero-dependency validation engine in `src/utils/gots_compliance.py`:

```
Material Formulation (Fibers + Chemical Inputs + Processing Tier)
                          |
                          v
         +----------------------------------+
         |  GOTSValidator.evaluate_blend()  |
         +----------------+-----------------+
                          |
     +--------------------+--------------------+
     |                                         |
     v                                         v
+------------------------+           +------------------------+
| 1. Organic Fiber Ratio |           | 2. Chemical RSL Filter |
| - Threshold Checks     |           | - Prohibited Additives |
| - Synthetic Cap Check  |           | - Temp / pH Limits     |
+------------+-----------+           +------------+-----------+
             |                                    |
             +-----------------+------------------+
                               |
                               v
               +-------------------------------+
               | Compliance Decision & Report  |
               | - is_compliant: bool          |
               | - label_grade: LabelGrade     |
               | - audit_trail: List[str]      |
               +-------------------------------+
```

### Positive Consequences
* Provides instant, verifiable certification feedback during both manual queries and automated Pareto optimization.
* Fully decoupled from model training routines, ensuring independent verification.
